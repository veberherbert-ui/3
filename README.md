# 🔎 Авито Парсер для риэлтора

Браузерное расширение (Chrome / Яндекс.Браузер / Edge / любой на движке Chromium),
которое прямо на странице поиска Avito фильтрует объявления по вашим правилам:

- **ключевые слова** (с учётом падежей — «квартира» найдёт «квартиру», «квартиры»…);
- **слова-исключения** (например, отсеять «агентство», «посредник», «обмен»);
- галочка **«только собственники»** — убирает явные агентства;
- **диапазон цены**;
- 🔬 **глубокая проверка продавца** — заходит внутрь каждого объявления и на профиль продавца, чтобы:
  - отсеять тех, у кого **много активных объявлений** (частные риэлторы — порог настраивается);
  - убрать объявления со **стоп-фразами** на странице («Агентствам не беспокоить» и т.п.);
- результат — готовый список со ссылками, который можно **скопировать** или **выгрузить в CSV** (Excel);
- режим **«сканировать все страницы»** — расширение само пройдёт по выдаче и соберёт всё в один список.

Расширение работает **внутри вашего браузера** и читает те объявления, которые
Avito уже показал на странице. Оно **не** обращается к скрытому API Avito и не
качает данные с сервера — поэтому для сайта это выглядит как обычный человек, и
риск блокировки минимален.

## Установка (2 минуты)

1. Скачайте эту папку целиком на компьютер (кнопка **Code → Download ZIP** на
   GitHub, затем распакуйте; либо `git clone`).
2. Откройте в браузере страницу расширений:
   - Chrome: `chrome://extensions`
   - Яндекс.Браузер: `browser://extensions`
   - Edge: `edge://extensions`
3. Включите справа вверху **«Режим разработчика»** (Developer mode).
4. Нажмите **«Загрузить распакованное расширение»** (Load unpacked) и выберите
   папку с этим проектом (ту, где лежит файл `manifest.json`).
5. Готово — в списке появится «Авито Парсер».

> Обновлять расширение при выходе новой версии: скачали новую папку → на странице
> расширений нажали «Обновить» (кружок-стрелка) у карточки расширения.

## Как пользоваться

1. Зайдите на [avito.ru](https://www.avito.ru), задайте нужную категорию, город и
   свои фильтры поиска как обычно, откройте список объявлений.
2. Справа появится панель **🔎 Авито Парсер** (если свернули — нажмите фиолетовый
   кружок или иконку расширения в тулбаре).
3. Заполните поля:
   - **Ключевые слова** — через запятую. Например: `квартира, срочно, торг`.
     Можно вводить фразы: `без посредников, свободная продажа`.
   - Галочка **«должно содержать все ключевые слова»** — если нужно, чтобы
     совпадали *все* слова, а не хотя бы одно.
   - **Слова-исключения** — через запятую. Например: `агентство, посредник, обмен`.
   - **Только собственники** — отсекает объявления, которые явно от агентств.
   - **Цена от / до** — необязательно.
4. Нажмите **«Найти на этой странице»** — подходящие карточки подсветятся зелёной
   рамкой, а в панели появится список со ссылками и ценами.
5. Чтобы собрать сразу со всех страниц выдачи — **«Сканировать все страницы»**.
   Расширение будет переходить по страницам с паузами и накапливать результат.
   Остановить в любой момент — кнопка **«Стоп»**.
6. **«Копировать»** — список в буфер обмена (заголовок — цена — ссылка).
   **«Скачать CSV»** — файл для Excel/Google Таблиц со всеми полями.

Настройки фильтра сохраняются автоматически и подставляются в следующий раз.

### 🔬 Глубокая проверка продавца

Обычный «Найти» читает только карточки на странице выдачи. Чтобы проверить
**профиль продавца** и **текст объявления**, есть глубокая проверка — блок внизу
панели:

1. Сначала задайте ключевые слова и нажмите обычный поиск (или просто откройте
   нужную страницу выдачи).
2. В блоке «Глубокая проверка» задайте:
   - **порог** — «отсеять, если у продавца объявлений больше, чем N» (по умолчанию
     1 → останутся только те, у кого ровно одно активное объявление);
   - **стоп-фразы** — через запятую (по умолчанию «агентствам не беспокоить» и
     похожие).
3. Нажмите **«Проверить эту страницу (~20 шт)»**.

Что происходит: расширение по очереди открывает каждое отобранное объявление и
страницу его продавца (с паузами ~2 сек), затем:
- если в объявлении есть стоп-фраза → **убирает** его из списка;
- если продавец — явное агентство → **убирает**;
- если у продавца активных объявлений больше порога → **убирает** (это, скорее
  всего, частный риэлтор);
- остальные остаются с пометкой «✓ объявлений: N».

Внизу панели показывается сводка: сколько проверено, сколько оставлено и сколько
отсеяно и по какой причине. Остановить можно кнопкой **«Стоп»**.

> ⏱ 20 объявлений с проверкой профилей ≈ 1–2 минуты. Не запускайте это десятками
> подряд без пауз — иначе Авито покажет капчу (расширение это поймает и
> остановится, капчу проходите вручную).

## Важные оговорки (читайте)

- **Тип продавца — эвристика.** Avito далеко не всегда показывает в карточке
  списка, кто продавец. Галочка «только собственники» уверенно убирает *явные*
  агентства (по названию, рейтингу, словам «недвижимость/риелтор» и т.п.), но
  100%-й гарантии по одной карточке дать нельзя — финально тип виден уже внутри
  объявления. Расширение специально **не** выбрасывает объявления с неизвестным
  типом, чтобы не потерять реальных собственников.
- **Разметку Avito периодически меняет.** Если вдруг «Найти» перестало находить
  карточки — значит, поменялись селекторы. Их легко обновить в файле
  `src/parser.js` (списки `*_SELECTORS` в начале файла).
- **Счётчик объявлений продавца и стоп-фразы — эвристика по HTML.** Разбор
  страницы продавца (`countSellerAds`) и поиск стоп-фраз написаны по типовым
  признакам Avito, но точные селекторы могут отличаться на реальном сайте. Если
  видите, что число объявлений определяется неверно — пришлите один сохранённый
  HTML страницы объявления и страницы продавца (в браузере: Ctrl+S → «Веб-страница
  полностью»), и регулярки в `src/parser.js` (`countSellerAds`, `extractSellerUrl`)
  подгоняются под точные селекторы за пару минут. Логика при этом уже покрыта
  тестами (`npm test`).
- **Не гоняйте «Сканировать все страницы» десятками подряд.** Между переходами
  стоят паузы (1.5–3.5 сек), но при слишком активном обходе Avito может показать
  капчу. Если это случилось — пройдите её вручную, сканирование остановится само.
- Расширение читает только то, что видно на странице поиска. Телефоны и прочее,
  что Avito отдаёт только по клику, оно не собирает.

## Структура проекта

```
manifest.json        — описание расширения (Manifest V3)
popup.html/js        — маленькое окно по клику на иконку (показать/скрыть панель)
src/parser.js        — разбор карточек и логика фильтрации (+ стеммер падежей)
src/content.js       — панель на странице, сканирование, экспорт
src/panel.css        — стили панели
icons/               — иконки расширения
tools/make_icons.py  — генератор иконок
tools/test_parser.js — юнит-тесты логики фильтра
```

## Разработка

```bash
npm test          # проверить логику фильтрации (25 тестов, без браузера)
npm run icons     # перегенерировать иконки
```

Тесты покрывают чистую логику (`splitTerms`, `matches`, стеммер) — её можно
менять с уверенностью, что фильтрация не сломалась.
