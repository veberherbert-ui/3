# Железный дневник

Трекер силовых тренировок: журнал, графики прогресса, база упражнений, замеры тела.

## Текущее состояние

Один файл — `workouttracker.jsx` (~1350 строк). Написан как артефакт Claude:
хранение идёт через `window.storage`, сборки и зависимостей пока нет.

### Что внутри

| Вкладка | Что делает |
|---|---|
| Сессия | Сбор тренировки из дня, ввод подходов, таймер отдыха, пауза |
| Журнал | История тренировок, тоннаж, PR, календарь за 5 недель, экспорт |
| Графики | Прогресс по упражнению, тоннаж, недельный объём по мышцам, рекорды |
| База | Каталог из 101 упражнения, редактор дней, готовые сплиты |
| Тело | Замеры, % жира (Navy), ИМТ, FFMI, расчёт 1ПМ, калории |

### Зависимости

`react`, `recharts`, `lucide-react`, Tailwind CSS, шрифты Google (Oswald / Inter / JetBrains Mono).
